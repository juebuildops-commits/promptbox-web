## 1. 頁面類型定義 (Page Typology)

### 【事實提取】

- 單一固定路由，無動態參數、無查詢字串狀態。兩個語系版本都存在且都被預繪（頁尾連結 ⇒ `crawlLinks` 爬得到，**不需要**像 `/enterprise`、`/en/demo` 那樣明列 `nitro.prerender.routes`）。
- **內容分屬兩層，分界與 `/docs`、`/changelog` 完全相同**：
  - **版面**（`about.vue` + `about.json`）—— hero 三句、頁內目錄標題、署名。三語，受 `check:i18n` 管。
  - **正文**（`content/about/*.md`，四支）—— 走 `@nuxt/content` 的 `about` collection，**只有繁體中文**。非 zh-TW 語系渲染 `<ContentLocaleNotice />`。
- 🔴 **正文放 content 而非語系檔，是為了不欠翻譯債**：`en` 不是骨架語系（`check-i18n.mjs` 的 `SKELETON` 只有 `ja`），空字串會直接擋建置 ⇒ 這一頁若進語系檔，等於上線當天就欠一整頁英文。見 [webplan D2](../../webplan/關於我頁.md)。
- **四個章節由 collection 的 `stem` 昇冪推導**（`1.why` → `2.how` → `3.status` → `4.origin`），與 `/docs` 同一種排序來源。要插一節就在檔名前綴給號，不必改頁面。
- **頁內目錄是 `<ol>` + `#anchor`**，錨點值來自 frontmatter 的 `anchor`。它是本頁唯一的導覽機制 —— 沒有側欄、沒有 scroll-spy（`/docs` 有，本頁刻意沒有：四節的閱讀順序是線性的，敘事本身有前後依賴）。
- **主導覽沒有本頁入口，只有頁尾有。** 這不是漏掛：桌機 nav 在 **lg（1024–1279px）已滿**，第 7 項會擠出容器（`AppHeader.vue` 的 `NAV` 無 `flex-wrap`）。數字見 [webplan D5](../../webplan/關於我頁.md)。
- **正文樣式走 `.about-prose`，不是 `.docs-prose`。** 後者的字彙不含 blockquote，h3 間距也偏小（本頁的 h3 是敘事段落的節拍器，不是條目標題）。三張表格是**手刻 HTML + Tailwind class**，與 `content/docs/5.secrets.md` 同一種寫法。
- 🙈 **檔案裡有五段 HTML 註解，那不是廢稿，是「藏起來但保留」。** 作者 2026-09-07 用 `<!-- -->` 把三列邊界、整節「兩句我不會說的話」、三條不做清單藏了（理由：**作者覺得這樣講出去太死**）。<br>🔴 **編輯時不要順手清掉** —— 清了就再也看不出這一頁曾經打算講什麼、以及為什麼沒講。清單與逐條影響在 [主張與依據 §二之五](../主張與依據.md)。<br>⚠️ 註解 HTML 表格列時，`<tr>` 與 `</tr>` **必須一起進註解**：只包住中間會留下一個沒有 `<td>` 的空 `<tr>`，線上會多出一條空白橫列（2026-09-07 發生過一次，已修）。
- **三個 `::notice` 全部是「這段話很重要」的訊號**，不是補充：`warning`（誠實但書）、`danger`（明文邊界）、`warning`（沒有匯出功能＋跨機解不開）。blockquote 則刻意做成低調側註，兩者在視覺上不可互換。

### 【推論分類】

**信任論證頁（Trust Argument），形式為第一人稱的作者自述。**

判定依據：本頁不傳遞新的產品事實 —— §二講的加密三層、MCP 行為、六條邊界，`/docs` 與 `/privacy` 都已用第三人稱講過。
它改變的是**陳述者**：從「這個軟體會…」變成「**我**決定讓它…，而這是我沒做到的地方」。

這正是 [07_what-we-dont-do.md](07_what-we-dont-do.md) 的分類，而本頁是它的**職能繼承者**（該頁 2026-09-03 自頁尾下架後成為孤兒頁）。
差別在於 07 只有「結論」（六件不做的事），本頁多了**來由** —— 那也是 [WL-003 §2](../../Wishlist/DONE/003.WL_關於我頁.md) 當初開這一頁的唯一理由。

漏斗位置：**頁尾 → `/about` → （無出口）**。本頁刻意是死路，見 §3。

### 🔴 出站連結：零條

**本頁正文不含任何 `<a>`。** 這是決策不是遺漏（[webplan D4](../../webplan/關於我頁.md)）：

- 提到價格時寫「**具體價格與早鳥方案在定價頁**」，**不給連結**。
- 提到 MCP、機密卡片、校驗碼時**不連 `/docs`**，即使 `/docs` 講得更細。
- **不連 `/what-we-dont-do`**，即使兩頁的「不做清單」同源。

理由：本頁接手的正是 07 下架後留下的位置，如果又把內容分散出去，就退回 [WL-003 §1](../../Wishlist/DONE/003.WL_關於我頁.md) 警告的「第四份副本」。
它的說服力來自**一口氣讀完**。

⚠️ **因此本頁在站內是一個吸收節點（sink）**：進得來、出不去（除了共用的頁首頁尾）。
要加連結之前先回去讀 D4 —— 加第一條連結會讓後面每一條都變得合理。

**只有頁尾一條**，兩個語系都有（`common.footer.about`）。
🔴 這使本頁與 `/enterprise`（零入口）、`/demo`（語系不對稱）並列為**入口最脆弱的三個路由**：

## 4. 問題解決與意圖解析 (Problem & Intent)

**它解決的問題**：一個要求使用者交出 API key、並宣稱完全不連網的產品，
在轉換路徑上缺的最後一塊不是技術證明（`/docs`、`/privacy` 已經給滿），而是**「這是誰」**。
[BRD-05](../../refer/BRD/BRD-05_行銷與獲客.md) 押的是「可驗證性」而非利益誘因型裂變 ——
而可驗證性需要一個**具名的、會為錯誤負責的人**站在後面，否則「你不必相信我」這句話沒有主語。

**它刻意不解決的**：

- **不做轉換。** 沒有 CTA、沒有下載鈕、沒有訂閱表單。頁尾以外的行動點是零。
- **不談錢。** 「這一頁不談錢，是刻意的」寫在頁面上。
- **不承諾功能。** 結尾給的是紀錄（開工日、版本數），不是路線圖。

**最可能被侵蝕的地方**（依風險排序）：

1. ~~**「兩句我不會說的話」** —— 每一句都是「說了會更好賣」的話，而它們現在只活在這一頁。~~
   🙈 **已於 2026-09-07 隱藏**（理由：**作者覺得這樣講出去太死**）。**這一條排第一，而它確實是最先消失的一段** —— 排序本身被驗證了，保留原文不刪。
2. **邊界表** —— 表格比散文更容易被「精簡」。2026-09-07 已由六列減為三列（同上），**留下的第 1 列（一般卡明文）仍是 C2 的本體，不可再減**。
3. **零出站連結** —— 這是最容易被善意破壞的一項，因為每一條連結單獨看都合理。
4. **「如果有一天我不做了」** —— 措辭未拍板（Q1），最可能被整段改寫，而它同時是全頁**唯一**主動講出「沒有匯出功能」的地方。
