# 頁面分析：會員專區（/account）

> **來源**：`Src/app/pages/account.vue`
> **最後查核**：2026-09-14（階段五 5a+ 上線）

---

## 一、頁面類型定義

* **推論分類**：會員應用專區（User Dashboard / Account Portal）兼授權憑證展示節點。
* **技術性質**：純 SPA 客戶端渲染（`routeRules: { '/account': { ssr: false } }`），消除 SSG 預繪與 Auth 的 Hydration 衝突。
* **主要目的**：為登入使用者提供個人基本資料管理、早鳥席次資格確認、官方二進位產物快速下載（/dl 轉址），並依據 Q12 方案 A 展示 Ed25519 授權碼文字框與複製功能。

---

## 二、核心內容映射

| 區塊 | 內容元素 | 意圖與主張 |
| :--- | :--- | :--- |
| **Hero 橫幅** | 標籤「會員中心」、標題「個人帳號專區」、副標題說明 | 清楚界定個人專屬空間 |
| **展示模式提示** | 琥珀色警告框（未配置 `SUPABASE_URL` 時呈現） | 安全降級，保證無連線環境不壞版、不噴錯 |
| **個人基本資料** | Google 帳號頭像、名稱、Email、登入/登出按鈕 | 呈現 Google OAuth 連動狀態 |
| **早鳥席次標章** | 「早鳥 150 名席次保留」綠色/品牌色卡片 | 兌現 D25 承諾，強化早鳥註冊之專屬感 |
| **授權憑證展示** | 當前方案狀態（Free）、Pro 授權碼卡片、一鍵複製 | 落實 Q12 方案 A，提供 App 端設定頁標準參考 |
| **快速下載面板** | Windows (.exe / .zip)、macOS (.dmg) 卡片 | 指向 `/dl/[platform]` 語意化端點，高效率取得產物 |

---

## 三、連結拓樸分析

* **入站連結**：
  * 全站 `AppHeader.vue` 右側「登入 / 會員專區」按鈕（桌機與行動選單）。
* **出站連結**：
  * 定價頁 `/pricing`（「升級至 Pro」按鈕）。
  * 下載代理 `/dl/win`、`/dl/win-zip`、`/dl/mac`（觸發 302 重新導向至 Cloudflare R2）。

---

## 四、問題解決與意圖解析

1. **打破死鎖**：藉由實體化的會員專區，確立授權碼採「直接複製 compact JWS 字串」而非「密鑰檔案拖曳」，為 App 端的 Electron 設定頁與離線驗證提供具體介面標準。
2. **零金流風險**：此頁面全程不經手信用卡扣款與不可逆 Webhook，做壞了可隨時回滾。
