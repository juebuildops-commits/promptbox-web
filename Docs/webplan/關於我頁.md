## 1. 為什麼現在做

[WL-003](../Wishlist/DONE/003.WL_關於我頁.md) 原本卡在兩個外部條件（P2 公司登記、P6 產品改名），Priority 判為 Medium。
**2026-09-07 創辦人裁示提前做**，理由不是條件成就，是**站上出現了一個洞**：

「我們不做什麼」頁已於 2026-09-03 自頁尾導覽下架（語氣過死、內容過少），
路由與內容都還在，但**全站沒有任何入口連得到它** —— 於是 [BRD-05 §5](../refer/BRD/BRD-05_行銷與獲客.md)
所說「放棄清單本身就是行銷素材」那份資產，實質上等於不存在。

`/about` 是那份資產的替代品，而且職能更大：它同時回答「這是誰做的」與「它不會變成什麼」。

## 2. 決策

| # | 決策 | 理由 |
| --- | --- | --- |
| **D1** | **`/about` 接手 `/what-we-dont-do` 的職能，且不連向它** | 創辦人裁示「都做在 about 這頁」。留著兩份會退回 [WL-003 §1](../Wishlist/DONE/003.WL_關於我頁.md) 警告的「第四份副本」，撞上 [文件規則 §6](../文件規則.md)「正本永遠不要有兩份」 |
| **D2** | 🔴 **正文放 `Src/content/about/*.md`，不放語系檔** | 本頁 95% 是長篇第一人稱敘事。放語系檔 ⇒ `check:i18n` 會要求 `en` 逐句翻譯（`en` 不是骨架語系，空字串直接擋建置）⇒ 等於用一頁翻譯債換一頁文案。走 content 則沿用**階段三 D-16 已經訂好的分界：版面三語、`content/` 只有 zh-TW** |
| **D3** | **只上繁體中文**。`en` 只有版面（hero／meta／頁尾標籤）＋ `<ContentLocaleNotice />` | 創辦人裁示「先快速上線」。與 `/docs`、`/changelog` 完全一致的既有路徑，英文讀者看得到原文而不是 404 |
| **D4** | 🔴 **本頁不對外連任何站內頁面**，提到定價時寫「在定價頁」但不給連結 | 創辦人裁示「不要外聯」。這頁的說服力來自**一口氣讀完**；把內容分散出去就退回 D1 要解決的那個問題 |
