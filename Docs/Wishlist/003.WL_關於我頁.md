## 1. 功能名稱：`/about`「關於我」頁

**問題 / 運用機會**

- 目前 8 頁（index／download／pricing／docs／changelog／privacy／what-we-dont-do／enterprise）**沒有 about**。
- 產品要求使用者把密鑰交給它保管、而且承諾完全不連網 —— 這種產品的轉換路徑上，「這是誰做的」是實打實的缺口。
- 🔴 **但這頁的素材不在 repo 裡。** grep 過 [BRD-01 定位與市場](../refer/BRD/BRD-01_定位與市場.md) 與 [BRD-05 行銷與獲客](../refer/BRD/BRD-05_行銷與獲客.md)：**沒有品牌故事、沒有團隊敘事、沒有創辦人段落**。BRD 講的是市場、圈層、獲客，不是「我們是誰」。
- 🔴 **而且很可能變成第四份副本。** [what-we-dont-do](../../Src/app/pages/what-we-dont-do.vue) 已經在做「關於我」通常在做的事（六件不做的事 + 五句不說的話＝價值觀陳述）；首頁 FAQ 有信任敘事、privacy 有立場。再開一頁，正好撞上 [文件規則 §6](../文件規則.md)「正本永遠不要有兩份」。

## 2. Proposed Solution

- **先定義這頁要說什麼別頁沒說的。** what-we-dont-do 給的是**結論**，沒給**來由**。about 講來由：
  - 為什麼一個人做這個東西
  - 為什麼 local-first 到願意放棄雲端營收（放棄清單有結論，沒有動機）
  - 為什麼「誠實紅線」是紅線、不是文案風格（C1／C2 的來歷，見 [App 事實依據 §二](../appsync/App事實依據.md)）
  - 現在是什麼身分、走到哪一步 —— 含誠實揭露：尚未登記公司、尚未購買程式碼簽章、Pro 未上架
- 路由 `/about`；導覽列位置待定（頁尾 or 主導覽）。
- 與 what-we-dont-do 互相連結，各自守住一半，不重寫對方的內容。

## 3. Potential Value（Priority 代表策略重要性，非開發順序）

- **對使用者**：補上信任鏈最後一段 —— 技術上的不連網已經講滿了，缺的是「人」。
- **對產品成長**：獨立開發者敘事本身就是 [BRD-05](../refer/BRD/BRD-05_行銷與獲客.md) 講的擴散素材，比功能列表好轉貼。
- **可能的指標改善**：下載轉換率、訂閱表單填寫率。

## 4. Priority

**Medium** —— 值得做，但**卡在兩個外部條件**上，不是工的問題。條件到位前寫，有一半機率要重寫。
