## 1. 功能名稱：`/about`「關於我」頁

**問題 / 運用機會**

- 目前 8 頁（index／download／pricing／docs／changelog／privacy／what-we-dont-do／enterprise）**沒有 about**。
- 產品要求使用者把密鑰交給它保管、而且承諾完全不連網 —— 這種產品的轉換路徑上，「這是誰做的」是實打實的缺口。

# 關於 PromptBox

## 一、我為什麼還是做了這個

### 起點是一個很小的困擾

我最常做的事，是打到一半不小心按到 Enter，把半成品送了出去。所以我改成先在記事本裡打草稿，想清楚了再貼過去——然後桌面上開始堆記事本。一個月後，我已經分不清哪個在處理什麼。

**而其中幾個裡面有 API key**——讓程式代你去用某個服務的通行碼，等於一把可以刷你帳單的鑰匙。

我原本只想做個小東西：變數、快速查找、複製內容。就這樣。我沒有打算做一個跟安全有關的東西，我只是嫌煩。

### 然後我發現，AI 讀得到那些檔案

這不是漏洞。你叫 AI 幫你改東西，它當然要看得到你的檔案——這是它能幫上忙的前提。

問題不在它讀。**問題是「該不該讀」這件事，從頭到尾只有它自己在判斷。** 球員兼裁判。

而且這不只是工程師的問題。你的 AI 助理能讀你的雲端硬碟、能讀你的筆記、能讀你整包貼過去的設定檔——都是同一件事。它需要看得夠多才能幫上忙，於是它就看得到全部。**你從來沒有被問過。**

### 所以它變成了一個保險庫

要回答的問題因此變成：**怎麼讓 AI 用得到你的東西，但不是全部。**

這件事沒辦法靠承諾，只能靠架構。所以我把它切成很少的幾條路，每一條都能被檢查：

- **出去：零條。** PromptBox 不會自己連上網路。沒有更新檢查、沒有使用統計回報、沒有授權驗證、沒有任何形式的回傳。
- **進來：兩條。** 一條是你，在畫面上操作；另一條是 AI，只能走同一台電腦裡的專用通道。沒有第三條。
- **機密卡片：內容不會自己出去。** 標成機密的卡片有自己的密碼，內容是加密存放的。AI 要用它的時候會先問你，你同意才放，而且每一次都會留下紀錄。

### 為什麼連自動更新檢查都拔掉

這是最容易被當成潔癖的一項，所以我講清楚。

早期的 PromptBox，每次啟動都會連上網檢查有沒有新版。這是所有桌面軟體的常態，我當時也沒多想——直到我意識到：**那是一個我沒有告訴使用者、而且他沒有按過任何按鈕的連線。**

對一般軟體，這頂多是個隱私瑕疵。對一個「保管你 API key」的軟體，它讓「不外傳」這句話變成一句**只能相信、不能查證**的話。而我要的效果剛好相反：**我希望你不必相信我。**

所以我把整套自動更新的程式碼刪掉了，接著把最後一個會連外的東西——原本要向 Google 的伺服器拿的字型——改成直接包進軟體裡。現在對外連線的來源是 **0**，而且有 7 項自動測試在盯著它：任何人（包括未來的我、包括 AI）想把連網能力加回來，測試會直接失敗，那一版就出不去。

代價我也照實說：**你不會知道有新版本。** 新版我用 email 通知，你自己到官網下載、直接覆蓋安裝，資料留在原地。這是我用「你不會被自動通知」換「它不會偷偷連線」，我認為對這個軟體是划算的交換。

### 一句誠實的但書

我說「完全不連網」的時候，指的是 **軟體不會自己連線**。有兩件事我要主動說清楚，不等你來抓語病：

1. **要讓 AI 用得到你的卡片，軟體會在你自己的電腦上開一個對內的窗口。** 只有同一台電腦上的程式連得進來，網路上的人連不到。而且**它預設是關閉的**，要你自己去開。
2. **你明確點擊**官網或回報表單的連結時，會由你的瀏覽器開啟。那是你在連網，不是軟體在連網。

## 二、它實際上是怎麼做的

這一節比一般「關於」頁詳細，理由很單純：**這個軟體的賣點是可驗證，那就不能只給結論。**
你不必看懂每一個名詞——但看得懂的人，應該有東西可以查。

### 用了什麼

| 部分       | 用什麼                                                                       |
| ---------- | ---------------------------------------------------------------------------- |
| 桌面程式   | Electron                                                                     |
| 畫面       | Vue 3 + Vite + Tailwind CSS + Pinia                                          |
| 資料庫     | SQLite，整個檔案以 **SQLCipher** 加密                                        |
| 卡片加密   | **scrypt** 金鑰派生 + **AES-256-GCM**（公開的標準組合，不是我自己發明的）    |
| 金鑰保管   | 交給作業系統（Windows 走 DPAPI，綁你的電腦帳戶）                             |
| AI 介面    | MCP（Model Context Protocol）官方 SDK                                        |
| 介面語言   | 繁體中文 / English / 日本語                                                  |
| 字型       | Inter（SIL OFL 1.1）＋ Material Symbols（Apache 2.0），**隨軟體打包，不向外取用** |

### 你的資料在哪裡、被誰保護

資料是**你電腦上的一個檔案**：Windows 上它在 `%APPDATA%\EYChen\Vault\vault.db`。沒有雲端副本，沒有帳號，沒有伺服器。

保護分三層，而且它們擋的東西不一樣：

1. **整個資料庫是加密的。** 解鎖它的金鑰是隨機產生的，交由作業系統保管、綁定你這台電腦的使用者帳戶——**這一層對所有使用者永遠免費、無上限、絕不設限。**
2. **機密卡片在上面再疊一層：** 用**你自己設的密碼**另外加密，卡片的內容、變數預設值、型別定義各自獨立上鎖。這層的鑰匙只在你腦子裡，我這邊沒有。
3. **AI 要用機密卡片，必須你當場按下允許。** 不會因為 AI 開口就交出去。

> 🔴 **這裡有一個我必須先說的分界**：上面第 2 點只適用於**設了密碼的機密卡片**。
> **一般卡片的變數預設值是明文存在資料庫裡的，而且永遠會是**——沒有密碼就沒有金鑰，這不是還沒做，是做不到。
> 整個資料庫仍然受第 1 層保護，但那一層擋的是「別人把你的硬碟拿走」，不是「同一台電腦上的其他程式」。

### AI 是怎麼拿到東西的

PromptBox 內建一個給 AI 用的介面（業界共通的 MCP，Model Context Protocol），Cursor、VS Code、Claude Desktop、Claude Code、Windsurf、Cline、Gemini CLI 等工具都接得上。運作方式：

- **只接受同一台電腦上的連線。** 虛擬機、Docker 容器、雲端都連不進來——這是刻意的，不是還沒支援。
- **預設不啟動。** 要你自己在設定裡打開。理由是：連線用的通行碼是明文寫在 AI 工具的設定檔裡的，介面永遠開著等於窗戶永遠沒關。
- **每個 AI 工具一把自己的通行碼**，可以個別撤銷，而且有流量上限。
- 每張卡片都有一顆**眼睛**：對 AI 顯示或隱藏。隱藏的卡片，AI 連它存在都不知道。
- **「有密碼」與「對 AI 隱藏」是兩件獨立的事。** 你可以讓 AI 知道「你有一張叫做『正式站 API key』的卡」，但內容仍然每次都要問你。
- **AI 傳來的參數一律忽略。** 變數的值只來自你填的，AI 不能覆寫人類的決定——這是程式結構上做不到，不是靠自律。

### 我沒有保護到的地方

一個保管密鑰的軟體，最該寫清楚的是它**沒做到**什麼。以下是目前所有已知的邊界，沒有一條是意外，每一條都是當初刻意留下紀錄的決定：

| #   | 邊界                                                                                   | 性質                                                                       |
| --- | -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 1   | **一般卡片的變數預設值是明文**（機密卡片的已經加密）                                   | **永久**。沒有密碼就沒有金鑰                                               |
| 2   | 作業系統的金鑰保管功能不可用時，資料庫會**退回不加密開啟**                             | 取捨：不這樣做，某些環境下你會完全打不開自己的資料                         |
| 3   | **離線可驗證與防破解在數學上不可兼得**                                                 | 選了離線，所以付費授權是弱驗證，接受一定比例被破解                         |
| 4   | 機密卡片解鎖後，明文留在畫面那一層的記憶體裡，主程式只能「請求」它清除，**不能保證抹掉** | 對照 AI 那一側：那份明文完全由主程式持有，清除是確定的。**兩邊的保證強度不同** |
| 5   | 機密卡片解鎖後切到別的視窗，明文最長會留在記憶體與被遮住的畫面上 **10 分鐘**           | 目前的取捨，而且相對前一版是**真實的防護下降**——換掉的是三個互相衝突的例外規則 |
| 6   | 機密卡片的**名稱與描述**，只要沒有按眼睛隱藏，AI 就看得到                              | 內容、變數值、型別定義都在密碼裡；**名稱與描述不是**                       |

**忘記機密卡片的密碼＝那張卡的內容永久打不開。** 沒有後門，沒有救援信箱——那兩樣東西一旦存在，這個軟體的前提就不成立了。（所以所有密碼欄位都可以切換顯示，這是為了降低打錯字的不可逆風險。）

## 三、它現在是什麼狀態、我靠什麼活

### 平台支援

| 平台                | 狀態                                                                                                                      |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **Windows 10 / 11** | ✅ 可用，提供安裝檔與免安裝版                                                                                              |
| **macOS**           | 🚧 **還沒有正式版本。** 程式碼裡該處理的都寫好了，但**在第一個 mac 版真的做出來之前，我不會說它可用**——沒驗過的東西我不講 |
| Linux               | 目前沒有計畫                                                                                                              |

### 商業模式

**核心免費，進階買斷。** 三件事說清楚：

- **免費版是完整的軟體，不是試用版。** 整個資料庫加密、機密卡片、密碼鎖、AI 授權、操作紀錄、AI 介面、變數、串聯——都在裡面。免費版的邊界是**數量**（卡片總數、機密卡片張數、串聯卡張數、AI 通行碼數量），不是能力。
- **安全能力永遠不會變成付費牆。** 加密不加價，授權窗不加價，自動上鎖不加價。付費版賣的是數量上限與紀錄匯出，**不是「更強的加密」**——那句話我不會說，因為它不是真的。
- **付費是買斷，附 12 個月更新權。** 付一次，永久可以用當時的版本；更新權到期只代表不能再下載新版，**已經裝好的版本照常永久跑**。軟體執行時**從不檢查到期日**，也不需要——它根本不連網。另有給公司的商業授權，走**榮譽制**：功能與個人版完全相同，軟體這一端一樣不做任何檢查。

### 我不會做什麼

一個保管你密鑰的軟體，最該講清楚的不是它會做什麼，是它**不會**變成什麼。以下幾件我不做，而且不打算改：

- **不做雲端同步。** 資料留在你的電腦上是這個軟體的前提，不是可以拿掉的功能。
- **不做團隊協作與權限管理。** 那需要我幫你保管一份資料在我的伺服器上。我不想要那份資料，你也不該給我。
- **不賣資料、不接廣告。** 這句話每個軟體都很好講，所以請看上面的「出去：零條」——資料連出去的路都沒有，這比我保證什麼都可靠。
- **不做 prompt 市集、不抽成。** 我不經營一個要有人氣才活得下去的地方，那會讓我開始在意錯的東西。
- **不做 prompt 版本控制、A/B 評測、成效追蹤。** 這些是工程師的工具，加進來會讓其他人打不開這個軟體。

**我知道這張清單對生意不好。** 不做雲端就沒有訂閱收入；不留你的資料，你想換掉我隨時可以走。把所有能鎖住你的東西一條一條拿掉之後，我手上就沒有籌碼了。這些我都算過——**一個保管你密鑰的軟體，如果要靠鎖住你才活得下去，那它一開始就不該存在。**
