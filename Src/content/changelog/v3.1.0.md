- <span class="text-lg">🔗</span><span>**卡片串聯**：在串聯資料夾用 `{{@prompt:N}}` 遞迴組合多張卡片，含循環偵測與深度限制。</span>
- <span class="text-lg">🔓</span><span>**機密釋放（Consent）**：機密卡片可設釋放策略（never / once / session），AI 請求時需輸入密碼授權。</span>
- <span class="text-lg">🧾</span><span>**釋放稽核**：每次機密釋放（允許 / 拒絕 / 逾時）留下完整紀錄，MCP 面板可審閱。</span>
