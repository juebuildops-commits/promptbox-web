- <span class="text-lg">📋</span><span>**串聯卡片的展開結果可以複製了**：Preview 分頁新增複製鈕，複製到的字串與畫面上看到的是同一份。展開失敗、或正在重新展開的期間會停用——不擋的話會安靜地複製到上一次的結果。</span>
- <span class="text-lg">🌏</span><span>**語言設定終於記得住**：切換介面語言後重開軟體，語言還在（先前每次啟動都會退回英文）。首次啟動仍為英文，不做語言偵測。</span>
- <span class="text-lg">💾</span><span>**存檔失敗不再關掉視窗**：過去無論成敗都關窗，被規則擋下時剛寫好的內容會跟著消失。現在存檔失敗會留在編輯器裡，訊息也明講「內容還留在編輯器裡」。</span>
- <span class="text-lg">🚫</span><span>**把機密卡片移進串聯資料夾會明白擋下**：這個動作本來就不被允許，但過去視窗照關，使用者以為已經存好了。</span>
- <span class="text-lg">📁</span><span>**新增卡片時預選你當前所在的資料夾**：在某個資料夾裡按新增，資料夾欄位就是它。先前那個「預設值」其實只是清單的第一格，會跟著你拖曳排序而改變。串聯資料夾同時補上配額預檢。</span>
- <span class="text-lg">🎨</span><span>**提示訊息的圖示與顏色跟著類型走**：失敗訊息不再配一個綠色打勾。</span>
