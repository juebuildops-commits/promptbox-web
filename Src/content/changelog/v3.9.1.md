- <span class="text-lg">🔍</span><span>**貼上 API 密鑰主動提醒**：編輯卡片時貼上常見 API 金鑰（如 OpenAI、AWS、GitHub、Slack 等）會即時彈出提示，引導一鍵轉為機密卡片保護。</span>
- <span class="text-lg">🔑</span><span>**修正「設為機密卡片」加密時機**：轉換為機密卡片時，確保直接加密當前編輯器中的最新內容，避免時序問題造成密鑰洩漏。</span>
- <span class="text-lg">⚠️</span><span>**變數預設值明文警示**：於一般變數的預設值欄位貼上敏感金鑰時，將顯示警示外框提醒該欄位不受密碼保護。</span>
- <span class="text-lg">ℹ️</span><span>**本機金鑰綁定與遷移提醒**：新增說明提醒資料庫金鑰與本機系統帳戶綁定，以利使用者掌握跨電腦搬移與資料備份邊界。</span>
