- <span class="text-lg">🔑</span><span>**「設為機密卡片」現在保護的是你剛貼上的那一份內容**：過去那顆按鈕加密的是資料庫裡的舊內容——卡片變成機密卡片、密碼也設好了，而剛貼上的金鑰從頭到尾沒有被寫入，更沒有被保護。順序改為**先問密碼、再寫入、最後加密**：中途取消，金鑰不會以明文留在資料庫裡。</span>
- <span class="text-lg">🔍</span><span>**貼上疑似 API 金鑰時當場提醒**：主編輯區偵測到常見的金鑰前綴（OpenAI／Stripe／AWS／GitHub／Slack 與 PEM 私鑰）就出現提示，可以直接把這張卡設為機密卡片。偵測只在你自己輸入時觸發，不會每次開卡都跳一次；規則刻意保守——寧可漏報，也不要用誤報把你訓練成無視提示。</span>
- <span class="text-lg">⚠️</span><span>**變數的預設值也會偵測**：命中時整個變數面板轉為琥珀色外框，加一行警語提醒**那一格不受密碼保護**。設定頁可以關掉這個標示，但**說明文字不會跟著關掉**。</span>
- <span class="text-lg">💾</span><span>**勸你設密碼的同時，把代價講完**：新增一則說明——資料庫的金鑰交給作業系統保管、綁在這台電腦的使用者帳戶上，換一台電腦或重灌之後，**整個資料庫（包含沒有設密碼的一般卡片）都可能開不起來**。軟體目前沒有匯出／備份功能，直接複製檔案也不保證解得開。</span>
