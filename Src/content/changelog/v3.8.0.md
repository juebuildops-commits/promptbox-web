- <span class="text-lg">🔐</span><span>**機密卡的變數與型別定義一併加密**：一張機密卡現在有三份密文（內容、變數、型別定義），共用一次派生的金鑰、各自獨立的 IV。**卡片內容、變數的名稱與預設值都在同一組密碼裡面**。</span>
- <span class="text-lg">⚠️</span><span>**沒有設密碼的一般卡片，變數預設值仍是明文**：這是永久的邊界不是待辦——沒有密碼就沒有金鑰。要保護某個值，就把那張卡設成機密卡片。</span>
- <span class="text-lg">🔑</span><span>**存檔時再要一次密碼**：改動內容或變數後重新加密需要金鑰，而解鎖流程結束時密碼就已丟棄（金鑰與密碼都不快取）。只改標題或說明不會問。</span>
- <span class="text-lg">🛡️</span><span>**一般卡的變數填值不再被誤清**：鎖回廣播加上卡片型別守衛。過去它會清掉一般卡的填值（而那些值本來就明文存在資料庫裡，清畫面一個位元組都保護不到），卻漏掉串聯卡引用來的機密明文。</span>
- <span class="text-lg">🔄</span><span>**卡片一變更就撤銷該卡的 AI 授權**：改了變數或換了密碼，等於收回存取權，AI 不會再沿用授權窗裡的舊值。</span>
- <span class="text-lg">🚪</span><span>**切換視窗不再是上鎖條件（誠實記帳：這是防護下降）**：解鎖後切到別的視窗，明文會留在記憶體與被遮住的螢幕上，最長到閒置逾時（10 分鐘）為止。保留閒置 10 分鐘／鎖定螢幕／系統睡眠／手動撤銷四個失效條件。離開座位請鎖定螢幕，不要只是切換視窗。</span>
