### 新增卡片

1. 點擊主畫面的「新增 Prompt」按鈕。
2. 填寫 **標題**、**內容**（支援 Markdown 語法），並可加上說明、標籤、選擇收納資料夾。
3. 儲存後卡片會即刻顯示於卡片牆，左下角標註 `#id` 編號（方便在 MCP 或串聯時精準引用）。

### 一鍵複製

每張卡片右下角皆有專屬複製按鈕，點擊一下即把完整內容送進系統剪貼簿，圖示會短暫變成 ✓ 提示成功。核心流程就是：**找到卡片 → 點一下複製 → 貼上直接用**。

### 即時搜尋與檢視切換

- **全局搜尋**：頂部搜尋框同時比對標題、內容與標籤，提示詞破百條後依然秒級命中。
- **我的最愛**：點選卡片星號 ⭐ 標記常用 Prompt，側欄一鍵快速過濾。
- **檢視模式**：右上角支援網格檢視（預設）與緊湊列表檢視切換。
