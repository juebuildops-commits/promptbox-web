變數樣板讓單一份 Prompt 適用於千變萬化的情境。在內容中使用雙大括號定義動態變數：

```text
請扮演資深 {{角色}}，用 {{語氣}} 的口吻，
針對以下主題撰寫一篇 {{字數}} 字的重點大綱：

主題：{{主題}}
```

### 使用流程

1. 儲存卡片後，右側會自動生成 **變數面板**，列出所有偵測到的 `{{變數}}`。
2. 在面板填入當次的值（亦可為常用變數設定預設值）。
3. 點擊複製時，變數自動替換代入；未填值的變數自動保留 `{{佔位符}}` 原貌，絕不無聲丟失文字。

::notice{type="info" icon="check"}
**人類策展原則（v3.7.0）**

PromptBox 堅持「值由人類策展決定」。當 AI 透過 MCP 呼叫卡片時，AI 傳入的參數一律被忽略，輸出完全以您在 PromptBox 填入的策展內容為準，確保 AI 不隨意竄改人類預設的變數。
::
