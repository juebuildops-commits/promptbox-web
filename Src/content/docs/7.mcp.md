PromptBox 內建本機 **MCP 伺服器**（支援 Streamable HTTP 與 SSE），讓 Cursor、VS Code、Claude Desktop、Windsurf、Claude Code、Cline 等 AI 工具直接取用您的 Prompt 資產。

### IDE 設定範例 (JSON)

```text
{
  "mcpServers": {
    "promptbox": {
      "url": "http://127.0.0.1:<PORT>/mcp",
      "headers": {
        "Authorization": "Bearer <YOUR_TOKEN>"
      }
    }
  }
}
```

- **本機限定安全**：MCP 伺服器僅監聽 `127.0.0.1`，支援具名 Token、600 req/min 速率分桶。
- **背景常駐 (System Tray)**：關閉主視窗後 App 縮小至系統匣繼續運行，MCP 服務不中斷。
- **釋放稽核紀錄**：支援一鍵「全部清除」紀錄（符合 ADR-007 邊界），全程透明。
