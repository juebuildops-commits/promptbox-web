### 你會看到什麼

在 Windows 上執行安裝檔時，可能會出現一個藍色視窗：

> **Windows 已保護您的電腦**
> Microsoft Defender SmartScreen 已防止無法辨識的應用程式啟動。

在 macOS 上，未來的版本釋出時也可能出現類似的 Gatekeeper 提示。

### 這個提示實際上在說什麼

它**不是**在說這個檔案有病毒，也不是誤判。它在陳述一件確實成立的事：

> 這個檔案沒有數位簽章，因此作業系統無法把它對應到一個**經過驗證的發行者身分**。

這句話是對的。**我們目前確實還沒有購買程式碼簽章憑證。**

### 為什麼還沒有

程式碼簽章憑證是**簽發給一個法定名稱**的 —— 公司或個人。而這個產品正處在兩件事的中間：

1. 產品名稱因商標問題即將更換
2. 公司登記尚未完成

現在購買，等於買一張要作廢的憑證，並且要在改名後重新驗證身分、重新簽發。所以這是一個**時序決定，不是省錢決定**。

### 我們不會請你忽略它

「這個警告是正常的，請點『仍要執行』」是惡意軟體散布頁最常見的句型。要求你降低戒心，跟我們主張的東西是矛盾的。

**我們提供的是讓你自己查證的方法。**

#### 一、核對檔案校驗碼

[下載頁](/download)公布了每個安裝檔的 SHA-256 校驗碼。下載後在終端機執行：

```powershell
# Windows PowerShell
Get-FileHash .\PromptBox-Setup-3.7.1.exe -Algorithm SHA256
```

```bash
# macOS / Linux
shasum -a 256 PromptBox-Setup-3.7.1.exe
```

輸出的雜湊值必須與下載頁上的完全一致。

::notice{type="warning" icon="lock"}
**校驗碼證明的是完整性，不是來源**

它能確認「你拿到的檔案，和我們發布的那一份完全相同」——也就是傳輸過程沒有損壞或被替換。

它**不能**證明「這份檔案確實出自我們之手」，因為校驗碼跟檔案放在同一個網站上。證明來源正是數位簽章的工作，而那一格我們現在是空的。誠實地說：這是目前的缺口。
::

#### 二、上傳到 VirusTotal 自行掃描

[VirusTotal](https://www.virustotal.com/) 會用數十種防毒引擎同時掃描你上傳的檔案，結果由第三方出具，我們無法干預或偽造。這是目前最接近「獨立驗證」的免費做法。

#### 三、用便攜版，不要安裝

如果你只是想先看看，[下載頁](/download)的免安裝便攜版解壓即用，不寫入登錄檔、不需要系統管理員權限。

### 它什麼時候會消失

我們會在**公司登記完成、且產品改名定案之後**購買憑證。這裡不寫死日期，因為那個日期取決於登記流程，而我們不想給一個做不到的承諾。

::notice{type="info" icon="check"}
**一個誠實的補充：買了憑證，警告也不會立刻消失**

SmartScreen 的信譽是**跟著憑證累積**的。一張全新的憑證起始信譽為零，簽了之後通常仍會跳一段時間的警告，直到累積足夠的下載量。

換句話說，這一頁不是一份撐到買憑證為止的臨時公告，它會陪我們走過相當長一段時間。
::

### 為什麼不乾脆等有簽章再發布

因為那會讓「等待」變成唯一的選項，而**你現在就能自己驗證這個檔案**——校驗碼與第三方掃描都是現成的。

我們選擇把缺口說清楚，而不是把它藏起來，或是等到看起來完美了才出現。
