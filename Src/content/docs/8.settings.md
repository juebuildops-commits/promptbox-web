### 版本更新方式

PromptBox 秉持完全不連網原則，App 內不做自動更新檢查。有新版本時會透過 **email 發布通知**，您可直接前往 GitHub Releases 或官網下載最新安裝檔覆蓋安裝，舊資料原地完整保留。

### 常見疑問排查

- **升級後找不到舊資料？**v3 首次啟動會將舊明文資料庫備份為 `promptbox.db.plain.bak` 並建立全新加密庫，舊資料可透過手動匯入還原。
- **IDE 連線 MCP 失敗？**請確認伺服器已在面板中手動啟動、Port 號與 Token 與 IDE 設定一致。

::notice{type="warning" icon="theme"}
**重設資料提醒**

設定頁提供「清除快取與重設」按鈕，執行後不可復原，請先備份重要提示詞。
::
